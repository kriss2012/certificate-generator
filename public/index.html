Integration Pathways

Connect the Certificate Generation & Verification System to your existing club website using 4 secure methods:

Embed Verification Portal in your Existing Website

Copy and paste this HTML snippet into any page on your club website to embed the verification widget: 

<!-- Embed Certificate Verification Widget -->
<iframe 
  src="http://localhost:3000/embed/verify" 
  width="100%" 
  height="650px" 
  frameborder="0" 
  style="border-radius:12px; border:1px solid rgba(255,255,255,0.1); box-shadow:0 10px 30px rgba(0,0,0,0.3);">
</iframe>

Direct Verification Button for Club Website Navbar

Add this button to your existing website header or footer to route members directly to verification: 

<a href="http://localhost:3000/verify" target="_blank" class="club-verify-btn">
  Verify Certificate Authenticity
</a>
